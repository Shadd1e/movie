# Citation policy for the final academic report

The current report contains **28 academic references dated 2021–2025**, plus four undated technical-documentation references. For the final submission, use **at least 25 academic sources from 2021 through the current year**, preferably retaining the strongest 28 already present and adding newer sources only when they materially support a claim.

Do not pad the bibliography. Every academic reference should be cited in the body, and every substantive claim that depends on literature should have an appropriate citation.

Technical documentation (Supabase, TMDB, DeepSeek, FastAPI, Next.js, scikit-learn and similar sources) should be cited where implementation facts are discussed, but should not be counted toward the academic-literature minimum.

The final bibliography should be checked for:
- publication year between 2021 and the current year for academic sources;
- author names and title accuracy;
- DOI or stable URL where available;
- one-to-one correspondence between in-text citations and reference-list entries;
- no invented or unused references;
- consistent citation style throughout the report.
